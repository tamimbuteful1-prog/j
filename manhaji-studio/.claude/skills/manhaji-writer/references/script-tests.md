# اختبارات النص (تُسجَّل في script.json > self_tests)

| الاختبار | السؤال | أساسي؟ |
|---|---|---|
| reality | هل الموقف محتمل الحدوث وطبيعي؟ | نعم |
| relation | هل القصة تجسد جوهر المفهوم فعلًا (لا ديكور)؟ | نعم |
| accuracy | هل كل تعريف ومثال ونتيجة صحيح ومطابق للمصدر (مع الصفحة)؟ | نعم |
| comprehension | هل يفهمه طالب الصف المستهدف دون الكتاب أثناء المشاهدة؟ | نعم |
| narrative | هل كل جملة تنتج عن السابقة؟ | نعم |
| brevity | هل توجد جملة يمكن حذفها دون فقد معنى ضروري؟ (يجب: لا) | لا |
| visual | هل لكل سطر فعل بصري واضح يمكن تحريكه؟ | نعم |
| standalone | هل تُفهم الحلقة دون حلقة سابقة؟ | لا |
| originality | هل تختلف جوهريًا عن كل ما في الذاكرة الإبداعية؟ | نعم |
| duration | هل المدة المقدرة ضمن 45–90 ث؟ | لا |

لكل اختبار: `pass` (bool) + `evidence` (جملة محددة، لا «نعم يجتاز»).

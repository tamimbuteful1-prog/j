# Educational QA
طابق مع المصدر (الصفحة إلزامية لكل حكم):
- [ ] كل تعريف بصيغته المعتمدة؛ المصطلح لم يُستبدل.
- [ ] القوانين/القواعد صحيحة وكاملة الشروط (لا قاعدة ناقصة شرطًا).
- [ ] الأرقام والحسابات صحيحة (أعد الحساب بنفسك).
- [ ] الأمثلة تمثل المفهوم دون حالة كاسرة غير معالجة.
- [ ] الاستثناءات الضرورية موجودة (مثل: «أو» الشاملة تشمل تحقق الاثنين).
- [ ] الهدف التعليمي (`learning_gap.after`) يتحقق فعلًا بنهاية الحلقة.
- [ ] لا معلومة خارج الدرس تُقدَّم كأنها منه.
- [ ] `locked_facts` لم تتغير في أي مرحلة لاحقة (نص الشاشة، الجدول، الترجمة).
Severity: أي خطأ علمي = blocker. نقص استثناء مؤثر = blocker. مصطلح غير دقيق = major.

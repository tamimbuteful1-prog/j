# Technical QA
الـ Orchestrator يجري الفحوص الآلية ويكتب `quality/technical_auto.json`. أنت تفسرها وتكمل الباقي:
| الفحص | المعيار |
|---|---|
| يفتح ويُشغَّل | ffprobe بلا أخطاء |
| الأبعاد/المعدل | 1080×1920، 30fps |
| الترميز | H.264 + AAC، yuv420p |
| المدة | تطابق الخط الزمني ± 0.2 ث، ضمن 45–95 ث |
| إطارات سوداء | لا مقاطع سوداء غير مقصودة (blackdetect) |
| الصوت | Integrated ≈ −14 LUFS (±1.5)، True Peak ≤ −1 dBTP، لا قص |
| النهاية | الصوت لا ينقطع قبل نهاية آخر سطر + ذيل ≥ 0.3 ث |
| الملفات | كل ما في `metadata.json > outputs` موجود |
| الأصول | لا أصول مفقودة (المحرك فشل = blocker) |

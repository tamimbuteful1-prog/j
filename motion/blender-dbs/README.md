# «الجندي الرقمي»: اختبار Blender (8 ثوانٍ)

لقطة واحدة متصلة في Blender: من مكتب التحقيق إلى شاشة الجوال، ثم إلى موجز الأخبار.
- كل العناصر مبنية من الصفر داخل المشهد. لا توجد أي صورة سابقة ولا لقطة من الفيديو المرجعي.
- الدقة 1080×1920، و30 إطارًا في الثانية، و240 إطارًا، والرندر بمحرّك Cycles.

## الملفات
| الملف | الوظيفة |
|---|---|
| `content.json` | **كل النصوص العربية**: قصاصات اللوحة، وأوراق المكتب، وتبويبات الموجز وبطاقاته. عدّل هنا ثم أعد البناء. |
| `build_scene.py` | يبني المشهد كاملًا ويحفظ `dbs_desk_feed.blend` (العناصر، والخامات، والإضاءة، والكاميرا، والتحريك). |
| `dbs_desk_feed.blend` | ملف Blender الناتج. كل غرض كائن مستقل في مجموعته. |
| `encode_preview.sh` | يجمع الإطارات في `dbs_test_8s.mp4` مع أول 8 ثوانٍ من مسار المؤثرات. |
| `fonts/` | خط Tajawal (رخصة OFL) بصيغة TTF. |

## التشغيل (Blender 5.0، أو `bpy` 5.0.1 مع Python 3.11)
```
pip install bpy==5.0.1 arabic-reshaper python-bidi fonttools brotli
python build_scene.py --preview --stills 0.5,2.5,6.6,7.6   # لقطات سريعة بنصف الدقة
python build_scene.py --render --samples 12                # 240 إطارًا إلى render/frames/
./encode_preview.sh
```

## بنية المشهد (المجموعات)
- **Room:** الجدار والأرضية.
- **Desk:**
  - الطاولة بخامة خشب إجرائية.
  - الكوب: الجسم، والقهوة، والمقبض.
  - الأوراق `Paper_news1` و`Paper_news2` و`Paper_notes`، وكل ورقة لها عناصرها التابعة: نصوص، وخطوط، وصورة.
- **Board:** اللوحة، وإطارها، وست قصاصات `Clip_*` بعناوينها، ودبابيس `Pin_*`، وخيوط حمراء `String_*` (منحنيات).
- **Lamp:**
  - القاعدة والذراعان والمفصل والغطاء واللمبة.
  - `Dust_In_Beam`: جسيمات صغيرة لا يضيئها إلا ضوء المصباح، فتظهر داخل الشعاع وحده.
- **Phone:** الجسم، والإطار، والشاشة، والزجاج. الزجاج خامة انعكاس حسب زاوية النظر، فيعكس المصباح فعليًا.
- **Feed:**
  - موجز الأخبار مبني فوق شاشة الجوال: الخلفية، وشريط التبويبات، وبطاقات `Card*` (التصنيف، والوقت، والعنوان، وصورة مصغّرة من أشكال بسيطة).
  - `Feed_Scroll` يحرّك البطاقات.
  - كل الخامات تستعمل قناع الشاشة (لا يظهر شيء خارج حدودها) و`ScreenPower`، وهو مفتاح إضاءة الشاشة مع اهتزاز الجوال.
- **Lights:**
  - `Lamp_Spot`: ضوء المصباح الدافئ، مع وميض التشغيل على توقيت المرجع.
  - `Moon_Fill` و`Wall_Bounce`: إضاءة باردة رمادية مزرّقة.

## النص العربي
Blender لا يشكّل العربية تلقائيًا. لذلك يمرّ كل نص عبر `arabic_reshaper` و`python-bidi` قبل وضعه في كائن نص.
- النص الأصلي محفوظ في الخاصية `source_text` لكل كائن.
- للتعديل: غيّر `content.json` ثم أعد تشغيل `build_scene.py`.
- إذا غاب شكل حرف من الخط، يُستبدل تلقائيًا بالحرف الأساسي.

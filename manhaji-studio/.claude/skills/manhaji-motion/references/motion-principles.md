# مبادئ الحركة

| المبدأ | التطبيق |
|---|---|
| Anticipation | تمهيد خفيف قبل حركة مهمة (رفع بسيط قبل السقوط في السلة). |
| Easing | `EASE.out` للوصول، `EASE.inOut` للكاميرا، `EASE.in` للخروج. لا حركة خطية. |
| Staging | فعل واحد مهم في اللحظة؛ البقية تهدأ/تخفت. |
| Timing | الحركة تصل على beat الكلمة المنطوقة (offset سالب صغير ≈ −0.1 ث لأن العين تسبق الأذن). |
| Follow-through | ارتداد خفيف بعد الهبوط، تمايل بسيط بعد التوقف. |
| Continuity | انتقالات متصلة سببيًا: match cut، تحول الشكل، العنصر يقود الكاميرا. لا انتقالات جاهزة. |

## ردود الفعل الدلالية
- TRUE: هبوط مريح + حلقة تأكيد + صوت `true_chime`.
- FALSE: رد فعل مباشر وواضح — اهتزاز قصير/وميض أحمر/عنصر شبحي منقط مكان المفقود + `false_hit`.
- لا تكرر نفس الرد بنفس الشكل في كل حالة: غيّر الزاوية/الإيقاع.

## ممنوع
- كل العناصر تتحرك معًا.
- زووم/اهتزاز بلا معنى.
- مؤثر انتقالي أهم من المعلومة.

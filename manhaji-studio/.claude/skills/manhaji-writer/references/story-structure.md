# بناء القصة

## السلسلة السببية
موقف → حيرة → سؤال → اكتشاف → تطبيق → نتيجة.
اختبرها بقراءة أول جملة من كل قسم متتالية: يجب أن تُكوّن قصة قصيرة متصلة.

## التوزيع الزمني (إرشادي)
| القسم | المدة |
|---|---|
| hook | 0–8 ث |
| context | 8–20 ث |
| bridge + explanation | 20–55 ث |
| demonstration | 55–80 ث |
| conclusion | آخر 5–10 ث |
وزّع حسب تعقيد الدرس لا حسب القالب.

## الجسر التعليمي
- يجيب عن سؤال **نشأ داخل القصة** ("طيب، خلونا نفهم الفرق!").
- ممنوع الانتقال المفاجئ إلى «تعريف: …».
- المصطلح يُقدَّم كاسم للشيء الذي رأيناه للتو.

## التطبيق (Demonstration)
- غيّر المدخلات داخل نفس الموقف وأظهر النتيجة كل مرة.
- غطِّ **كل الحالات اللازمة للفهم الصحيح**، خاصة الحالة التي يخطئ فيها الطلاب
  (المنطق: «أو» صحيحة عندما يتحقق الجزآن معًا؛ الاستقراء: المثال المضاد).
- لا تكرر نفس البنية اللفظية لكل حالة؛ نوّع الإيقاع (سؤال، سرعة، مفاجأة).

## الخاتمة
- قصيرة، تُثبت المفهوم، ويمكن أن تعود للموقف الأول محلولًا.
- السطر الأخير ثابت الهوية: «وهذا درس <العنوان>، من مادة <المادة> للصف <الصف>.» (قابل للتعديل في config).

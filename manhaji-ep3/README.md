# منهجي — العبارات الشرطية (الجرس الذكي) — Short 1080×1920

النسخة الحالية **معاينة بتوقيت مخطط**: الهوك بصوت تميم الحقيقي، وبقية المشاهد مبنية على النص المكتوب
(يظهر كترجمة أسفل الشاشة) مع موسيقى ومؤثرات، بانتظار التسجيل الصوتي.

## عند وصول التسجيل الصوتي
1. ضع الملف في `public/media/voice_source.mp4` (أو m4a وعدّل الاسم في `scripts/mix.py`).
2. في `src/timeline.json`:
   - أضف `segments`: الأجزاء المحتفظ بها من التسجيل بالثواني (لحذف الصمت والتكرار).
   - استبدل كل قيمة في `cues` بوقتها الحقيقي داخل التسجيل، وكذلك بدايات/نهايات `lines`.
   - احذف `duration` (يُحسب تلقائيًا) أو اتركه.
3. `python3 scripts/mix.py` ثم `npm run render`.

## الملفات
- `src/scenes/Hook.tsx` — الهوك (لوحة 3:4 حادة فوق خلفية ضبابية من نفس اللقطة) + انتقال البطاقة المقلوبة.
- `src/scenes/BellScene.tsx` — «لأن هذا جرس ذكي ويرن تلقائيًا في وقت محدد».
- `src/scenes/LogicScene.tsx` — الشرطية ← العكس ← المعكوس ← المعاكس الإيجابي.
- `src/scenes/Summary.tsx` — المصفوفة والخاتمة.
- `src/components/Captions.tsx` — الترجمة من `timeline.json → lines`.

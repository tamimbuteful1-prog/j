معيار

راجع نصك وافهم المراجع النظامية المرتبطة به قبل النشر

تقييم مساعد وفق المراجع المعروضة، وليس حكمًا قانونيًا نهائيًا.

1 المزود ومفتاح API

إنشاء مفتاح API — يُنشأ المفتاح لدى المزود وقد يتطلب تسجيل الدخول هناك، أما معيار نفسه فلا يحتاج تسجيل دخول.

ما هو مفتاح API؟

مفتاح API يتيح لهذه الصفحة إرسال طلبك إلى مزود الذكاء الاصطناعي عبر حسابك. قد تحتاج إلى تفعيل الفوترة أو إضافة رصيد. استخدام API له فوترة منفصلة عن اشتراك تطبيق المحادثة.

يبقى المفتاح في ذاكرة هذه الصفحة فقط: لا يُحفظ في المتصفح، ويُمسح عند إعادة تحميل الصفحة أو الضغط على «مسح المفتاح»، ولا يُرسل إلا إلى عنوان المزود الرسمي في ترويسة المصادقة.

يختار معيار النموذج المناسب تلقائيًا من النماذج المتاحة لحسابك.

2 المهمة

يبحث معيار في المراجع داخل متصفحك ويجهّز طلبًا كاملًا (التعليمات ونصك والمواد ذات الصلة). تنسخه وتلصقه في ChatGPT أو Claude، فيُحتسب على اشتراكك هناك دون مفتاح API ودون أي رصيد إضافي.

سياق اختياري يساعد على دقة المراجعة

لا تُدخل معلومات شخصية. هذه الإجابات تُرسل كما هي ضمن الطلب ولا يتحقق منها معيار.

سيُرسل النص والمراجع المختارة إلى المزود الذي اخترته لمعالجتها وفق سياساته. يُستخدم المفتاح مؤقتًا داخل هذه الصفحة. إدخال المفتاح في المتصفح لا يخلو من مخاطر.

الإلغاء يوقف انتظار الاستجابة، لكنه لا يضمن إلغاء تكلفة ما عالجه المزود بالفعل.

المراجع وحدود التغطية

معيار موقع ثابت: لا حسابات ولا قاعدة بيانات للمستخدمين ولا أدوات تتبع. عند استخدام مفتاح API يُرسل الطلب من متصفحك مباشرة إلى المزود الذي تختاره.

# توجيه الإصلاحات
| نوع المشكلة | owner |
|---|---|
| خطأ في النص/الفكرة/الحقائق/ورقة التسجيل | writer |
| storyboard، مشهد، تصميم، حركة، نص شاشة، توقيت beat | motion |
| مزامنة الصوت، قص الهوك، المستويات، الترجمة النهائية، الدمج | assembly |
| تسجيل ناقص/خاطئ، لقطة هوك غير صالحة، تعارض علمي في الكتاب، موافقة حقوق | human |
لا تكتب «حسّن الحركة». اكتب: «S05، beat false1: العيش يُسحب ببطء (0.8 ث) فيضيع رد الفعل؛ اجعل السحب ≤ 0.45 ث مع EASE.out وأظهر الشبح المنقط قبل شارة FALSE».

# «جندي على الحدود الرقمية» — حلقة موشن جرافيك عمودية

- **الملف:** `digital-border-soldier.mp4`: 1080×1920، 30 إطارًا/ث، 60 ثانية، صوت AAC ستيريو.
- **بلا نص مضاف.** النص الوحيد في الفيديو هو ما في الشهادة وفي موقع منصة معيار.
- **الصوت:** مؤثرات مولَّدة برمجيًا بالكامل، مع مساحة للتعليق الصوتي.

## ترتيب المشاهد (يتبع نص التعليق)
| الزمن | المشهد |
|---|---|
| 0–7 | غرفة التحقيق: المصباح يشتغل والجوال يهتز |
| 7–15 | منشور مسيء، ثم ردود تتطاير، ثم شبكة تنتشر |
| 15–23 | لوحة الأدلة: خيوط خفية تقود إلى يد تحرّك الحسابات |
| 23–33 | ردود الفعل: نسكت، نرد، ننجرّ، ثم «إيش الحل؟» |
| 33–44 | جندي على الحدود الرقمية: القبة تفحص ما يصل إليها |
| 44–54 | جوال يتصفح منصة معيار، ثم الشهادة على المكتب مع تكبير على «مشروع متميّز» |
| 54–60 | الدرع وفيه صورة صاحب المبادرة |

## الهوية البصرية: «غرفة التحقيق»
أسلوب نوار: ظلام، وإضاءة مصباح، وظلال عملاقة على الجدار.
- **ألوان:** كهرماني للمحقّق، وأحمر للتضليل والاستفزاز، وبنفسجي لكشف الخيوط الخفية، وأخضر للتحقق والحدود الرقمية.
- **الوجه المجوَّف:** رمز الحساب الوهمي.

## ملفات المصدر
- `index.html`: معاينة حيّة (▶).
- `lib.js` و`scenes1-3.js` و`scene7.js`: المشاهد.
- `assets.js`: تحميل الأصول.
- `engine.js`: ترتيب المشاهد والمعالجة النهائية.
- `audio.py`: يولّد `audio.wav`.
- `render.js`: التصيير النهائي (`node render.js`).

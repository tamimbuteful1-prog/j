# مرجع بصري: حلقة المنطق (`../manhaji-logic/`)

| القرار | السبب |
|---|---|
| ممر بقالة 3D بحركة كاميرا واحدة متصلة حتى المنتجين | ينقل المشاهد من الواقع للمشكلة دون قطع |
| عزل المنتجين بعمق الحقل + «؟» مجسمة بينهما | الحيرة صارت شيئًا مرئيًا |
| عنوان يتبدل رابطه بين «و» و«أو» مع تردد النظر | الشك نفسه مكتوب |
| المنتجات تبقى عند الانتقال للشرح (match cut) | القصة تحمل الشرح |
| TRUE = العيش يسقط في السلة؛ FALSE = يُسحب منها | قيمة الصواب فعل لا كلمة |
| «أو» تكبر وتصير ∨؛ مساران يلتقيان في سلة واحدة | «يكفي واحد» تُرى |
| ∨ ينقلب 180° فيصير ∧ | نفس الشكل مقلوبًا — رابط بصري صادق |
| قفل بمفتاحين يفتح عند 2/2 | «يجب الاثنان» آلية لا جملة |
| الحالة الثالثة في FALSE بزاوية كاميرا وإيقاع مختلفين | منع الرتابة مع ثبات الهوية |
| العيش يمينًا والصامولي يسارًا طوال الحلقة | استمرارية مكانية |
تعلّم الآلية. لا تعِد استخدام البقالة/السلة/القفل لدرس آخر إلا إذا كانت هي الاستعارة الأدق فعلًا وسجلت السبب.

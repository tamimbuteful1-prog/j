# «جندي على الحدود الرقمية» — حلقة موشن جرافيك عمودية (٤٥ ث)

- **الملف النهائي:** `digital-border-soldier.mp4` — ‏1080×1920، ‏30 إطارًا/ث، صوت AAC ستيريو.
- **بلا أي كتابة** على الشاشات أو البطاقات. القصة تُروى بالصورة وحركة الكاميرا والمؤثرات الصوتية فقط.
- **الصوت** مؤثرات مولَّدة برمجيًا بالكامل، وتُركت مساحة للتعليق الصوتي.

## الهوية البصرية: «غرفة التحقيق»
| العنصر | الدلالة |
|---|---|
| أسود حبري + ظلال ستائر مائلة | غرفة تحقيق بعد الحادثة، ضوء ليلي، أسلوب «نوار» |
| كهرماني `#FFB060` | مصباح المكتب، ضوء المحقّق |
| أحمر إنذار `#FF2E40` | التضليل والاستفزاز والانتشار |
| بنفسجي فوق بنفسجي `#A060FF` | كشف الخيوط الخفية والحسابات المنسّقة |
| أخضر تحقّق `#26E8A0` | الوعي والتحقق والمصدر والحدود الرقمية |
| الوجه المجوَّف (قناع بعينين فارغتين) | حساب وهمي أو مصدر مجهول |
| شرائط التنقيح السوداء | نصوص «محذوفة»؛ لا كتابة مقروءة إطلاقًا |

## ملفات المصدر
- `index.html` + `lib.js` + `scenes*.js` + `engine.js`: المحرك والمشاهد على Canvas. افتح `index.html` في المتصفح واضغط ▶ للمعاينة الحيّة.
- `audio.py`: توليد المؤثرات الصوتية (`python3 audio.py` → `audio.wav`).
- `render.js`: التصيير النهائي (`node render.js` → MP4، يتطلب Playwright وffmpeg).

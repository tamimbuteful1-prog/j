# مرجع: حلقة «المنطق» (MATH-G10 — عبارة الوصل والفصل)

النص المعتمد كان:
- hook: «أبوي قال لي أجيب عيش وصامولي… ولا قال عيش أو صامولي؟!»
- context: «رحت البقالة، وأول ما وصلت نسيت وش أبوي طلب مني بالضبط!»
- bridge/explanation: قيمة الصواب ← «جيب عيش أو صامولي» عبارة فصل ← يكفي جزء واحد على الأقل.
- demonstration: لو قال «عيش وصامولي» = عبارة وصل ← لازم الاثنين؛ نسيت العيش = False، نسيت الصامولي = False.
- conclusion: «وهذا درس المنطق، من مادة الرياضيات للصف الأول الثانوي.»

## لماذا نجحت (هذه هي الآلية التي تتعلمها)
1. **الحيرة اليومية = المفهوم نفسه.** النسيان بين «و» و«أو» هو حرفيًا الفرق بين الوصل والفصل.
2. **الهوك من قلب الموقف** ويحمل الكلمة المحورية («أو») دون أن يسمّي الدرس.
3. **العناصر ملموسة وقابلة للعدّ:** منتجان + سلة ← حالات الصواب تُرى ولا تُحفظ.
4. **تغيير المدخلات داخل نفس الموقف** أعطى جدول الصواب كاملًا.
5. **الحالة التي يخطئ فيها الطلاب** («أو» مع تحقق الاثنين = True) ظهرت صراحة.

## ما لا يجب نسخه
البقالة، المنتجات، السلة، جملة «أبوي قال لي…»، بنية «لو نسيت X؟ False». هذه صارت في الذاكرة الإبداعية كـ «مستخدمة».

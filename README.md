# يومي — منصة الجدول الزمني المرئي

منصّة ويب لتنظيم اليوم على شكل **جدول زمني فعلي** مكوّن من خانات كل ٣٠ دقيقة —
لا قائمة مهام. تكتب المهمة فتراها ممتدّة داخل خانات وقتها الحقيقي، مع خط يوضّح
أين وصلت في يومك الآن.

> تطبيق ثابت (HTML + CSS + JavaScript) بلا خطوات بناء. افتح `index.html` مباشرة
> أو انشره على أي استضافة ثابتة مثل GitHub Pages.

---

## المزايا

**الجدول**
- محور زمني عمودي من الصباح إلى الليل، خانة مستقلة كل ٣٠ دقيقة (قابلة للتغيير إلى ١٥ دقيقة أو ساعة).
- المهمة تظهر ممتدّة داخل كل خانات وقتها: مهمة من ٤:٠٠ إلى ٥:٣٠ تغطّي ٤:٠٠ و٤:٣٠ و٥:٠٠.
- المهام المتداخلة تُوزَّع تلقائيًا على أعمدة متجاورة داخل اليوم.
- خط أحمر للوقت الحالي مع شارة الساعة، يتحدّث كل ٢٠ ثانية.
- الأيام السابقة تظهر بخلفية باهتة، والمهام المنتهية غير المنجزة تظهر مشطوبة بخطوط مائلة.

**التنقّل**
- شريط أيام الأسبوع: السبت – الأحد – الاثنين – الثلاثاء – الأربعاء – الخميس – الجمعة، مع نقطة تحت كل يوم فيه مهام.
- عرض **اليوم** وعرض **الأسبوع** (٧ أعمدة).
- تنقّل للأمام والخلف وزر "اليوم"، وعند الفتح يبدأ التطبيق مباشرة على جدول اليوم مع تمرير تلقائي إلى الوقت الحالي.

**التحكّم بالمهام**
- إضافة بالضغط على أي خانة، أو بالسحب على عدة خانات لتحديد المدة مباشرة.
- تعديل، حذف، تغيير الوقت، وتغيير المدة.
- **سحب وإفلات** لنقل المهمة بين الأوقات — وبين الأيام أيضًا في عرض الأسبوع.
- سحب الحافة العلوية أو السفلية لزيادة أو تقليل المدة.
- ضغطة مطوّلة (أو الزر الأيمن) تفتح قائمة سريعة: إكمال، تأجيل، تأخير ٣٠ دقيقة، نسخ ليوم آخر، تعديل، حذف.
- نسخ المهمة إلى يوم آخر.
- تراجع فوري بعد الحذف.

**التكرار**
- يوميًا، أو أسبوعيًا بأيام محدّدة، مع تاريخ انتهاء اختياري.
- مثال: المدرسة من ٧:٠٠ صباحًا إلى ٢:٠٠ ظهرًا، تكرار من الأحد إلى الخميس → تظهر تلقائيًا في كل هذه الأيام.
- عند تعديل أو نقل أو حذف موعد من مهمة متكررة يسألك التطبيق: **هذا الموعد فقط** أم **كل المواعيد**.

**الحالات**
`لم تبدأ` · `الآن` · `مكتملة` · `تم تجاوزها` · `مؤجلة` —
الحالات الزمنية تُحسب تلقائيًا من الوقت، والمكتملة والمؤجلة يحدّدها المستخدم.

**رأس اليوم**
التاريخ، اسم اليوم، عدد المهام، عدد المكتملة، إجمالي الوقت المخطط، المتبقي في اليوم،
والوقت المتاح غير المخطط، مع شريط تقدّم.

**شريط "الآن"**
المهمة الحالية ووقت انتهائها والمتبقي منها، ثم المهمة التالية ووقت بدايتها.

**التصنيفات والألوان**
دراسة، عمل، مشروع، رياضة، اجتماع، راحة، وقت شخصي — قابلة للإضافة وإعادة التسمية
واختيار أي لون لها.

**التصميم**
عربي RTL بالكامل، وضع فاتح وداكن (وتلقائي حسب النظام)، ويعمل على الكمبيوتر والجوال
مع الحفاظ على فكرة المربعات الزمنية على الشاشات الصغيرة (عرض الأسبوع يُمرَّر أفقيًا
ولا يتحوّل إلى قائمة).

**اختصارات لوحة المفاتيح**
`N` مهمة جديدة · `T` اليوم · `D` عرض اليوم · `W` عرض الأسبوع · `→` `←` تنقّل بين الأيام.

## التشغيل

```bash
# أي خادم ثابت
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو انشر المجلد كما هو على GitHub Pages (Settings ← Pages ← Deploy from branch).

بدون أي إعداد إضافي يعمل التطبيق في **الوضع المحلي**: البيانات تُحفظ في متصفح
الجهاز فقط (`localStorage`).

## الحسابات والحفظ السحابي (Supabase)

لتفعيل الحسابات ومزامنة المهام والجداول والتصنيفات والألوان والإعدادات بين الأجهزة:

1. أنشئ مشروعًا مجانيًا على [supabase.com](https://supabase.com).
2. من لوحة التحكّم افتح **SQL Editor ← New query**، والصق محتوى
   [`supabase/schema.sql`](supabase/schema.sql) ثم شغّله.
   ينشئ هذا الملف الجداول الأربعة ويفعّل *Row Level Security* بحيث لا يرى أي
   مستخدم بيانات غيره.
3. من **Project Settings ← API** انسخ:
   - `Project URL`
   - `anon public key`
4. أدخِلهما بإحدى طريقتين:
   - من داخل التطبيق: شاشة الدخول ← احفظهما في الحقلين ← **حفظ وربط**
     (تُخزَّن في متصفحك فقط).
   - أو ثبّتهما للجميع في `assets/js/supabase-config.js`:

     ```js
     window.SUPABASE_CONFIG = {
       url: "https://xxxx.supabase.co",
       anonKey: "eyJhbGciOi..."
     };
     ```

5. أنشئ حسابًا من التطبيق (بريد وكلمة مرور، أو رابط دخول عبر البريد).

> `anon public key` مفتاح عام مصمّم للعمل داخل المتصفح، وحمايته الحقيقية هي سياسات
> RLS في ملف الـ SQL. **لا تضع `service_role key` في هذا الملف أبدًا.**

### إعدادات إضافية في Supabase
- **Authentication ← Providers ← Email**: فعّل Email. عطّل "Confirm email" إن أردت
  دخولًا فوريًا بعد التسجيل.
- **Authentication ← URL Configuration**: أضف رابط موقعك في `Site URL`
  و`Redirect URLs` حتى تعمل روابط الدخول عبر البريد.

## بنية الملفات

```
index.html                  هيكل الصفحة
assets/css/app.css          التصميم كاملًا (متغيّرات ألوان + وضع داكن + استجابة)
assets/js/core.js           أدوات الوقت والتاريخ والألوان والثوابت
assets/js/store.js          طبقة البيانات: localStorage + Supabase
assets/js/schedule.js       توليد مواعيد المهام المتكررة، حساب الحالات، توزيع التداخل
assets/js/ui.js             بناء الجدول وشريط الأيام والرأس والنوافذ
assets/js/app.js            التحكّم: الدخول، السحب والإفلات، المحرّر، الإعدادات
assets/js/supabase-config.js  بيانات الاتصال (اختيارية)
supabase/schema.sql         جداول قاعدة البيانات وسياسات الأمان
legacy-chat.html            الصفحة السابقة في المستودع (محفوظة كما هي)
```

### نموذج البيانات

المهمة المتكررة تُخزَّن **مرّة واحدة** ومواعيدها تُولَّد عند العرض. أي تعديل على
موعد بعينه (وقت، عنوان، حالة، أو حذف) يُحفظ كـ *override* في جدول
`task_overrides` بمفتاح `<task_id>|<YYYY-MM-DD>`، فلا تتضخّم قاعدة البيانات
بصفوف مكرّرة.

الأوقات تُخزَّن كعدد دقائق من منتصف الليل (`0`–`1440`)، وأيام التكرار كأرقام
`0` = الأحد … `6` = السبت.

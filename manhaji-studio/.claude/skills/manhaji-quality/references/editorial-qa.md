# Editorial QA
- [ ] الهوك من قلب الموقف، يُفهم من أول مشاهدة، لا يكشف الحل، ≤ 8 ث.
- [ ] الموقف طبيعي ومحتمل.
- [ ] الرابط بالدرس واضح وغير مفتعل؛ القصة تحمل الشرح بعد الهوك.
- [ ] لا إطالة: لا جملة يمكن حذفها.
- [ ] لا تكرار لفكرة/موقف/آلية حيرة من الذاكرة الإبداعية.
- [ ] الأسلوب مناسب لعمر الصف؛ لهجة طبيعية؛ لا مبالغات.
- [ ] الخاتمة تثبت المفهوم (لا تحفيز عام).
- [ ] سطور التسجيل قابلة للنطق بنَفَس واحد.
Severity: هوك ضعيف/موقف مفتعل/تكرار = major. صياغة = minor.

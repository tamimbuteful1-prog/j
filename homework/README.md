# واجبات تميم تركي الحارثي – التعويض (بايثون + أمن سيبراني)

| المطلوب | الملفات للتسليم | ثريد الديسكورد |
|---|---|---|
| التاسك الشامل – بايثون | `python_task/تميم_الحارثي_الكلاس_بايثون.py` + `python_task/تميم_الحارثي_الكلاس_بايثون.pdf` | التاسك الشامل - بايثون |
| التاسك الشامل – أمن سيبراني | `cyber_task/تميم_الحارثي_الكلاس_سايبر.pdf` | التاسك الشامل - أمن سيبراني |
| بحث البايثون (موضوع 1: مسبار المريخ) | `python_research/تميم_الحارثي_الكلاس_بحث_بايثون.pdf` + `.py` | بحث البايثون |
| بحث الأمن السيبراني (موضوع 1: WannaCry) | `cyber_research/تميم_الحارثي_الكلاس_بحث_سايبر.pdf` | بحث الأمن السيبراني |

قبل التسليم:
1. غيّر كلمة `الكلاس` في أسماء الملفات (مثل `تميم_الحارثي_102_بايثون.py`) واكتب رقم الكلاس في الغلاف بدل `______`.
2. في البحثين: عبّ سطر «استخدام أدوات الذكاء الاصطناعي» (إلزامي حسب التعليمات).
3. شغّل ملفات `.py` بنفسك وخذ صور شاشة حقيقية للتشغيل.
4. افتح روابط المصادر وتأكد إنها تشتغل.

مصدر المستندات (HTML) في `build/`، والتحويل لـ PDF: `node build/render.js build/<file>.html <out>.pdf`

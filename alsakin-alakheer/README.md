# الساكن الأخير — سلسلة رعب نفسي متحركة (2.5D)

> **قسم مستقل** عن «منهجي» و«الحدود الرقمية». لا يشارك أيًا منهما الهوية أو الأصوات أو الكود.

سلسلة من 20 حلقة. الرعب يأتي من الغموض والصمت والمصادفات المستحيلة — لا وحوش ولا أشباح ظاهرة ولا دماء ولا Jump Scares متكررة.

## الهوية البصرية
- 2D مرسوم بعمق 2.5D (طبقات Parallax)، ألوان ليلية: أزرق ليلي، أخضر رمادي، أسود، مع ضوء أصفر دافئ خافت.
- إضاءة درامية: ضوء الممر من تحت الباب، ضوء القمر من النافذة، ضوء شاشة الجوال كمصدر رئيسي على الوجه.
- كاميرا بطيئة (Dolly / Push / Pan)، سكون مقصود، حبيبات فيلم وVignette.

## الاستمرارية (ممنوع تغييرها)
- **نواف:** 22 سنة، وجه نحيف، شعر أسود قصير، تيشيرت منزلي فحمي — `engine/src/art/nawaf.tsx` (نفس الألوان والنسب في كل لقطة).
- **الغرفة:** تخطيط واحد ثابت — `engine/src/art/room.tsx` (الدولاب يسار الباب، الباب في الجدار الخلفي، المقبض يسار، النافذة على الجدار الأيسر).
- **الأم:** لا تظهر جسديًا؛ صوتها فقط (مكتوم من وراء الباب، أو بخصائص مكالمة).

## التشغيل
`cd engine && npm install && npx remotion studio` · الصوت: `scripts/build_vo.py` يقطع التسجيل لسطور ويعالج صوت الأم ويضيف لحظات الصمت؛ `npm run sfx` يولّد المؤثرات المؤقتة.

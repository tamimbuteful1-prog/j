# Visual QA (من اللقطات والفيديو)
- [ ] التمثيل البصري صحيح علميًا (لا استعارة مضللة).
- [ ] في كل لحظة عنصر أهم واضح.
- [ ] الاستمرارية المكانية: المواقع والألوان الدلالية ثابتة.
- [ ] الألوان الدلالية بمعناها فقط (أخضر TRUE، أحمر FALSE…).
- [ ] النص داخل المساحات الآمنة، خارج شريط الترجمة، غير مقطوع.
- [ ] العربية: اتجاه صحيح، حروف متصلة، ترقيم في موضعه، رموز ∨∧ سليمة.
- [ ] لا عنصر يغطي الوجه في الهوك أو يغطي معلومة.
- [ ] الحركة تصل مع الكلمة المنطوقة (± 0.2 ث) في الفيديو النهائي.
- [ ] تنوع الحالات المتشابهة؛ لا رتابة.
- [ ] الانتقالات متصلة سببيًا؛ لا شرائح منفصلة.
Severity: تمثيل مضلل/نص مقطوع/عربية مكسورة = blocker. فقدان التسلسل البصري = major.

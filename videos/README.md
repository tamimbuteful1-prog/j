# فيديوهات شرح معيار (واجهة الجوال)

- `Meyar-OpenAI-Mobile.mp4`: إنشاء مفتاح OpenAI API وشحن الرصيد وربطه بمعيار.
- `Meyar-Anthropic-Mobile.mp4`: إنشاء مفتاح Claude API وشحن الرصيد وربطه بمعيار.

المواصفات: 1080×1920 (9:16)، 30 إطارًا/ث، H.264 مع مسار صوت صامت.
سُجلت اللقطات بمحاكاة جوال في Chromium عبر Playwright: مساحة عرض 390×844، وكثافة بكسل 3، ولمس، ومتصفح iPhone.

شارة أعلى كل لقطة تحدد نوعها:
- **لقطة حقيقية من الجوال**: معيار كاملًا، وصفحة دخول Claude Console وقائمتها على الجوال.
- **وثائق رسمية**: صفحات وثائق OpenAI وAnthropic على الجوال.
- **محاكاة توضيحية**: صفحات تتطلب تسجيل الدخول أو الدفع (Billing وAPI keys)، ومنصة OpenAI التي لم تُعرض في المتصفح الآلي. التسميات مأخوذة من الوثائق الرسمية.

المفاتيح المعروضة وهمية. ردّ المزود في خطوة «افحص النص» محاكى، أما معالجة معيار وعرضه للنتيجة فحقيقيان.

إعادة الإنتاج (من مجلد `source`): `node capture.cjs openai` ثم `node overlays.cjs openai` ثم `python3 compose.py openai Meyar-OpenAI-Mobile.mp4`.

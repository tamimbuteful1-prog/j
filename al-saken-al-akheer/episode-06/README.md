# الساكن الأخير | الحلقة 06 — الحارس

من هالحلقة نبدأ نستخدم **نظام تحريك شخصيات جديد**، مكتوب في `animatic/rig.js` عشان نستخدمه في الحلقات الجاية.

## نظام التحريك (`rig.js`)
كل شخصية مقسومة لأجزاء مستقلة، وكل جزء يدور على مفصله:

| الجزء | التفاصيل |
|---|---|
| الجسم | حوض ← جذع ← رقبة ← رأس. والذراعين: كتف ← ذراع علوية ← كوع ← ساعد ← رسغ ← يد. والرجلين: ورك ← فخذ ← ركبة ← ساق ← كاحل ← قدم |
| العيون | بياض مقصوص بقناع يمنع البؤبؤ من الطلوع برا العين، وقزحية وبؤبؤ ولمعة. الجفن العلوي والسفلي مستقلين (رمش، تضييق، اتساع)، وفيه ارتجاف عند الخوف |
| الحواجب | كل حاجب مستقل (ارتفاع، دوران، اقتراب من النص). التعبيرات الجاهزة: neutral · fear · shock · doubt · anger · sad · tense |
| الفم | شكل مستمر يتحكم فيه الانفتاح والعرض والابتسامة والشد. **حركة الفم أثناء الكلام مربوطة بارتفاع صوت التسجيل نفسه** (`voice_env.js`)، وما تشتغل إلا وقت ما تتكلم الشخصية داخل المشهد |
| الشعر | خلفي وأمامي، والغرّة تتحرك حركة ثانوية |
| الرأس | ميل وإيماءة والتفات بإيحاء 3/4 (الملامح تتحرك والجهة البعيدة تنضغط والأذن تختفي)، وفيه منظور جانبي ومنظور من الخلف |
| اليدين | خمس أصابع، كل إصبع ينثني لحاله. الوضعيات: مفتوحة، قبضة، إشارة، ماسك جوال، ماسك مقبض، متوترة، ممدودة، على الكتف، ماسك شريط، ضغط زر |
| المشي والجري | دورة بثني الركب وحركة الكاحل وتأرجح الذراعين وارتفاع وانخفاض الجسم. المسافة محسوبة من طول الخطوة عشان ما تنزلق الشخصية |

الشخصيات: `nawaf` · `father` · `guard` (أبو صالح) · `fireman`.

## الحلقة
- التسجيل بتوقيته الأصلي بالضبط. فرّغته كامل (130 مقطع)، والترجمة تتبعه حرفيًا.
- **المدة ≈ 3:20**، يعني أطول من حد YouTube Shorts وهو 3 دقايق، لأن الصوت لحاله 189 ثانية وما يصير نعدّل عليه.
- **الأماكن:** الصالة، والباب، والممر، وغرفة الحارس (شاشات مراقبة وجهاز VHS ورفوف أشرطة)، وشاشة المراقبة. وفيها ثلاث تسجيلات: الحريق بجودة VHS، وكاميرا المصعد، والبث المباشر.
- **النهاية:** «تفتحون الباب؟» وتحته «نفتح ونواجهه 🚪» و«نقفل وننتظر 🔒».

python3 timeline_vo.py narration.mp3 sil.txt .

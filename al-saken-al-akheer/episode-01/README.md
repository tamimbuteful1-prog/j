## 1. النص النهائي للراوي (جاهز للتسجيل)

**رموز الأداء:**
`/` سكتة قصيرة (نص ثانية) — `//` سكتة طويلة (ثانية كاملة) — **غامق** = الكلمة تُضغط بهدوء، لا بارتفاع الصوت.

---

**[الخطاف — صوت منخفض، كأنه يعترف بسر]**

أمي كانت تكلمني من ورا باب غرفتي… / وفي نفس الوقت، / كانت تكلمني بالجوال **من المستشفى**. //

**[الموقف — هادي، جمل عادية]**

أول ليلة لنا في العمارة الجديدة. /
صحيت الساعة **ثلاث وسبعطعش دقيقة** الفجر… /
على ثلاث دقات على باب غرفتي. //

*(مؤثر: طق… طق… طق — بدون كلام فوقها)*

سمعت صوت أمي: /
— «نواف، افتح الباب.»

**[تصاعد — السرعة تزيد شوي، فيه عدم تصديق]**

كنت بقوم… / بس جوالي اهتز. /
رسالة من أمي: /
«أنا وأبوك في المستشفى، بنرجع الصباح. لا تنسى تقفل الباب.» //

وقفت مكاني. /
ورجع الصوت من ورا الباب: /
— «نواف، افتح… أدري إنك صاحي.» //

اتصلت على أمي. / ردت. /
قلت لها: «يمه… أنتِ بالبيت؟» /
قالت: — «لا يا وليدي، وش فيك؟» /

وقبل ما أتكلم… / سمعت صوتها من ورا الباب يقول **نفس الجملة**: /
— «لا يا وليدي، وش فيك؟» //

نفس الصوت. / بنفس التوقيت. //

**[الاكتشاف — جمل قصيرة، تنفس طبيعي]**

قفلت الخط من الخوف. /
بعدها بثواني، وصلتني رسالة من رقم ما أعرفه: /
«لا تفتح الباب. هو للحين ما يعرف شكلك.» //
وبعدها رسالة ثانية: /
«ولا تطالع تحت الباب.» //

بس أنا… / كنت أطالع أصلًا. //

**[الصدمة — أبطأ، أوضح، هدوء مخيف]**

كان فيه ظل شخص واقف عند الباب. //
المشكلة؟ //
الظل كان **من جهتي أنا**. //
يعني اللي كان يطرق… / // كان واقف **داخل الغرفة**.

*(ينقطع الصوت — شاشة سوداء)*

## 5. الموقع والإكسسوار

**غرفة نواف** — يجب أن تبدو عادية جدًا:
- كراتين نقل مكتوب عليها بقلم أسود: «غرفة نواف» — «كتب» — «أغراض المطبخ».
- سرير بدون إطار، مرتبة على الأرض أو سرير بسيط.
- **مرآة قديمة بإطار خشبي** مسنودة على الجدار (أُحضرت مع العفش؟ أم كانت بالشقة؟ — لا يُشرح). **عنصر حاسم للحلقة 20.**
- باب خشبي بفراغ واضح تحته (2 سم تقريبًا) — ضروري لخط النور.
- مصدر الإضاءة الوحيد: نور الممر الأصفر من تحت الباب + ضوء الجوال + ضوء ليلي أزرق خفيف من الشباك.

**الإضاءة:** منخفضة لكن مقروءة. لا أحمر. لا ضباب.

**حل لقطة الظل (16–17):** شخص يقف ملاصقًا للباب من الداخل، والكشاف في الممر خلف الباب على مستوى الأرض، فينطرح ظل طويل داخل الغرفة. الكاميرا على الأرض بعدسة واسعة، والشخص خارج الكادر تمامًا.

## 7. توجيه الأداء الصوتي

- **نواف:** يحكي كأنه للحين ما صدق. ما يمثل الخوف، **يتذكره**. السرعة تزيد شوي من «كنت بقوم» لين «نفس التوقيت»، ثم ترجع تبطأ.
- **«المشكلة؟»** — تُقال كسؤال حقيقي، ثم سكتة ثانية كاملة.
- **آخر جملة:** أهدأ جملة في الحلقة كلها. بعدها مباشرة ينقطع الصوت.
- **الأم (مها):** دافئة، عادية جدًا، فيها قلق أمومي خفيف. **نفس التسجيل** يُستخدم للباب وللجوال — لا تُسجل مرتين.

## 11. النسخة الأولية للفيديو (Animatic)

المجلد [`animatic/`](./animatic) فيه نسخة أولية مرسومة للحلقة: المشاهد، وشاشات الجوال، والترجمة، والمؤثرات الصوتية، بنفس توقيت الجدول. **ما فيها صوت راوي** ولا صوت للأم؛ الحوار يبان كترجمة لين يتسجل الصوت الحقيقي.

- `episode-01.html` — افتحه بالمتصفح ويشتغل مباشرة (المؤثرات الصوتية موجودة في ملف MP4 فقط).
- `make_audio.py` — يبني مسار المؤثرات (الدقات، الاهتزاز، الإشعارات، الرنين، الدرون، التنفس).
- `render.js` — يصدّر الحلقة MP4 بدقة 1080×1920.

```bash
python3 make_audio.py ep01.wav && node render.js ep01.wav ep01.mp4
```

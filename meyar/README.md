# معيار

> انشر بوعي. راجع نصك وافهم المراجع النظامية المرتبطة به قبل النشر.

معيار موقع ثابت (HTML وCSS وJavaScript، دون خادم) يعرض تجربة بصرية حول «مقياس معيار» ثلاثي الأبعاد، ويقدّم مسارين للاستخدام:

1. **فحص نص باستخدام API**: «فحص نص» أو «اسأل معيار» بمفتاح المستخدم نفسه لدى OpenAI أو Anthropic. يبحث معيار محليًا في المراجع، ويرسل المقاطع ذات الصلة فقط، ثم يتحقق من الاستشهادات قبل عرضها.
2. **تحميل الملفات ونسخ البرومبت**: ملف ZIP فيه ملفات PDF الستة والبرومبت، يرفقها المستخدم في ChatGPT أو Claude. الإجابة تظهر داخل المساعد، ولا تعود إلى معيار.

ما يعرضه معيار تقييم مساعد وفق ست وثائق مرجعية فقط، وليس حكمًا قانونيًا نهائيًا.

---

## 1. التشغيل والنشر

المتطلبات للتطوير فقط: Node.js 18 أو أحدث.

```bash
cd meyar
```

```bash
npm install
```

```bash
npm run dev
```

بناء النسخة الثابتة في `dist/`:

```bash
npm run build
```

```bash
npm run preview
```

يولّد البناء تلقائيًا من ملفات المستودع: `dist/prompt.txt` و`dist/miyaar-references.zip` (البرومبت وملفات PDF الستة وملف README)، ونسخة من ملفات PDF في `dist/sources/` لروابط «فتح الصفحة في الملف الأصلي». لا يُكتب البرومبت أو الحزمة يدويًا، فلا يختلفان عمّا يستشهد به الموقع.

**النشر:** ارفع محتويات `dist/` كما هي إلى أي استضافة ملفات ثابتة (GitHub Pages أو Cloudflare Pages أو Netlify أو خادم عادي). المسارات نسبية، فيعمل الموقع من مجلد فرعي. على Vercel: اضبط **Root Directory** على `meyar`؛ الملف `vercel.json` يحدد البناء وترويسات الأمان. نسخة بناء جاهزة موجودة في `meyar/dist/`.

الاستضافات المجانية لها حدود في عرض النطاق وحجم الملفات (الحزمة نحو 31 م.ب). تكلفة التحليل لا يتحملها صاحب الموقع؛ كل طلب يُحتسب على مفتاح المستخدم.

**الصورة الشخصية:** لم تُرفق الصورة في بيئة التنفيذ، فيظهر حرف «ت» مكانها تلقائيًا. لإزالة الخلفية السوداء ووضع الصورة:


يحذف السكربت السواد المتصل بحواف الصورة فقط (فلا يمسّ الشعر أو الملابس الداكنة داخل الصورة)، ويكتب `public/media/tamim.webp`. راجع النتيجة بصريًا.

## 3. التصميم والحركة

- **الهوية:** خلفية عاجية دافئة، ونص فحمي، وبرتقالي محدود للتأكيد والمؤشر، والأخضر والأحمر داخل المقياس والنتائج فقط. قسم داكن واحد بإضاءة دافئة لعرض تفاصيل المقياس.
- **الخطوط:** Alexandria (للعناوين) وIBM Plex Sans Arabic (للنصوص)، مستضافة داخل الموقع عبر حزم Fontsource، دون تباعد حروف يفسد الاتصال العربي.
- **المقياس** (`src/gauge/`): نموذج Three.js مبني بالكود: جسم تيتانيوم مصقول بنقشة دائرية، وإطار شمبانيا متدرج، وحلقة داكنة بعلامات محفورة، وحافة فولاذية، وواجهة مطبوعة (المناطق: «لم يظهر تعارض» و«يتطلب معلومات» و«مؤشرات تعارض»، وعبارة «في حدود المراجع المفحوصة»)، ومؤشر برتقالي، وزجاج مقبّب بلمعة تنزلق مع الدوران، وإضاءة بيئية. لا ملفات نماذج أو صور خارجية.
- **الحركة:** التمرير طبيعي ولا يُعترض. مع التمرير ينتقل المقياس من الواجهة إلى المسرح الداكن، ويتغير منظوره، وتتباعد طبقاته، ويمر المؤشر على الحالات بالتتابع مع نصوصها، ثم تعود الطبقات ويختفي المقياس قبل أدوات الاستخدام. الحركة توضيحية فقط، ومكتوب ذلك تحت المقياس.
- **الأداء:** Three.js يُحمَّل بعد ظهور الصفحة (`import()` عند الخمول)، فالأزرار والأدوات تعمل فورًا. الرسم يتوقف حين يخرج المقياس من الشاشة أو تُخفى الصفحة. على الجوال والأجهزة الأضعف: دقة أقل وعدد أضلاع أقل.
- **البدائل:** صورة مصدّرة من النموذج نفسه (`public/media/gauge-poster.webp`) تظهر حتى يجهز WebGL، وتبقى إذا تعذر. مع «تقليل الحركة» يبقى المقياس ثابتًا، وتظهر نصوص المسرح كلها دون تثبيت. `?no3d` في الرابط يعطّل الطبقة ثلاثية الأبعاد للتجربة.

## 4. تقدير التكلفة قبل الإرسال

`src/cost.ts`. يُحسب من **الطلب الكامل الذي سيُرسل فعلًا**: التعليمات الثابتة، ونص المستخدم، والسياق، والمقاطع المختارة بالبحث المحلي. يُحوَّل عدد الحروف إلى نطاق توكنز (العربية بنسبة مختلفة عن JSON والإنجليزية؛ الإعدادات في `models.json` ← `estimate`)، ويُضاف للمخرجات نطاق من حد أدنى معتاد حتى الحد الأقصى المسموح (8000 توكن، ويشمل التفكير). يُضرب في سعر النموذج ويُحوَّل بسعر 3.75 ريال للدولار. يُعرض نطاقًا مع تاريخ الأسعار، ويوصف بأنه تقدير.

إذا اختار معيار عند الإرسال نموذجًا غير الذي حُسب له التقدير (لأن الافتراضي غير متاح في الحساب، أو مع OpenAI حيث يُختار النموذج من قائمة الحساب)، يتوقف قبل أي طلب مدفوع ويعرض تقديرًا محدّثًا وزر «تابع الإرسال».

## 5. المراجع: ما استُخدم وما استُبعد

جميع الملفات فُحصت من محتواها الفعلي، لا من أسمائها. البيانات الكاملة في `sources/documents.json`، وتظهر أيضًا في قسم «المراجع وحدود التغطية» داخل الموقع، كل وثيقة في صف قابل للفتح.

| المعرّف | الوثيقة | النوع | المواد | طريقة الاستخراج |
|---|---|---|---|---|
| `press-law` | نظام المطبوعات والنشر (م/32، 1421هـ) | نظام | 49 | طبقة نص رقمية فُكّت على مستوى الحروف |
| `press-law-exec-reg` | اللائحة التنفيذية لنظام المطبوعات والنشر (المعدلة 1439/11/9هـ) | لائحة | 99 | فك ترميز خط معيب بجدول حروف مُراجع بصريًا |
| `av-media-law` | نظام الإعلام المرئي والمسموع (م/33، 1439هـ) | نظام | 25 | ملف ممسوح ضوئيًا، نُسخ يدويًا وطوبق بصريًا |
| `av-media-exec-reg` | اللائحة التنفيذية لنظام الإعلام المرئي والمسموع | لائحة | 31 | فك ترميز خط بلا ترميز Unicode بجدول حروف مُراجع بصريًا |
| `gmedia-org` | تنظيم الهيئة العامة لتنظيم الإعلام (قرار 174، 1445هـ) | تنظيم واختصاصات جهة | المواد 1–3 | ملف ممسوح ضوئيًا، نُسخت الصفحات 1–5 |
| `age-rating` | التصنيف العمري (صفحة الهيئة العامة لتنظيم الإعلام) | دليل أو معيار رسمي تحتاج طبيعته تحديدًا | بلا ترقيم | طبقة نص رقمية |

**الأجزاء غير المعتمدة للاقتباس:**
- ملحقا اللائحة التنفيذية لنظام الإعلام المرئي والمسموع، (أ) دليل التراخيص و(ب) جدول المخالفات (صفحات PDF 26–56): جداول لم يُحفظ ترتيب أعمدتها عند الاستخراج. هي مخزنة ومعلَّمة بأنها غير معتمدة، ولا تُرسل إلى النموذج.
- تنظيم الهيئة العامة لتنظيم الإعلام، الصفحات 6–12 (مجلس الإدارة والشؤون المالية): لم تُنسخ، وهي خارج نطاق مراجعة المحتوى.
- نظام الإعلام المرئي والمسموع، الصفحة 2 (قرار مجلس الوزراء): لم تُنسخ.

**ملفات مستبعدة من الاستشهاد النظامي** (البصمات في `sources/documents.json`):
- تقرير حالة قطاع الإعلام في السعودية وفرص الاستثمار، الملخص التنفيذي 2024: تقرير قطاعي.
- تقرير حالة الطلب على المحتوى 2024: تقرير قطاعي.
- أربع محاضرات (إدارة التواصل والمنصات الإعلامية 1 و2، والوعي الإعلامي والمسؤولية الوطنية 1 و2): مواد تعليمية.

سبب الاستبعاد: لا يُستخدم تقرير سوقي أو محاضرة لإثبات مخالفة نظامية. هذه الملفات غير مضمّنة في المستودع.

### حالة التحقق من الحداثة

**لم تتحقق حداثة أي نسخة.** بيئة الإعداد لم تسمح بالوصول إلى `laws.boe.gov.sa` ولا `gmedia.gov.sa`، فلم يمكن مقارنة النسخ بالمصدر الرسمي، ولم يُسجَّل رابط رسمي لأي وثيقة (`official_url: null`). ملاحظات محددة:
- نظام المطبوعات والنشر: النص في الملف لا يُظهر أي تعديلات لاحقة. يلزم التحقق من وجود تعديلات، خاصة على مواد الضوابط والعقوبات (المادتان 9 و38).
- نظام الإعلام المرئي والمسموع ولائحته: يستخدمان أسماء جهات سابقة («وزارة الثقافة والإعلام»، «الهيئة العامة للإعلام المرئي والمسموع»). تنظيم 1445هـ المرفق أنشأ «الهيئة العامة لتنظيم الإعلام» محل تنظيم الهيئة السابق.
- اللائحة التنفيذية لنظام الإعلام المرئي والمسموع: لا تذكر تاريخ إصدار أو رقم قرار.

## 6. تجهيز المراجع وإعادة بنائها

```
sources/pdf/                 ملفات PDF الأصلية + SHA256SUMS
sources/text/*.txt           نسخ يدوي للملفات الممسوحة، مقسم بعلامات === PAGE n ===
sources/extracted/<id>/      نص مستخرج آليًا، ملف لكل صفحة PDF (لا يُحرر يدويًا)
sources/documents.json       بيانات الوثائق: النوع، الجهة، الإصدار، الحداثة، ملاحظات الاستخراج، المستبعدات
scripts/extract_all.sh       الخطوة 1: استخراج النص من ملفات PDF الرقمية
scripts/extract_royal.py     فك الترميز على مستوى الحروف (glyph) عبر جدول royal_map.py
scripts/extract_bukra.py     فك الترميز على مستوى الحروف عبر جدول bukra_map.py
scripts/normalize_letters.py توحيد ی/ھ/ک إلى ي/ه/ك
scripts/ocr.sh               OCR مساعد (Tesseract، العربية) لصنع مسودة النسخ اليدوي فقط
scripts/build_corpus.py      الخطوة 2: تقسيم المواد، والصفحات، والإحالات ← public/data/corpus.json
```

إعادة البناء الكاملة:

```bash
pip install pymupdf fonttools
```

```bash
npm run refs
```

إعادة تقسيم المواد فقط، بعد تعديل `sources/text` أو `documents.json`:

```bash
npm run corpus
```

**إضافة وثيقة أو تحديثها:**
1. ضع ملف PDF في `sources/pdf/` باسم ثابت بأحرف لاتينية صغيرة (مثل `new-law.pdf`).
2. إن كانت طبقة النص سليمة، أضف سطرًا في `extract_all.sh` يستخدم `extract_royal.py` (يعمل مع الخطوط ذات الترميز السليم). إن كان الملف ممسوحًا ضوئيًا، شغّل `scripts/ocr.sh` لصنع مسودة، ثم انسخ النص يدويًا إلى `sources/text/<id>.txt` بعد مطابقته بصريًا.
3. أضف بيانات الوثيقة في `sources/documents.json`: `segmenter` بقيمة `ordinal` للمواد المكتوبة بالكلمات، أو `numeric` للأرقام، أو `headings` للنصوص غير المرقمة. حدّث `reviewed_on` و`currency`، ولا تكتب `verified` إلا بعد مقارنة فعلية بالمصدر الرسمي.
4. شغّل `npm run refs` ثم `npm test`. اختبار سلامة المراجع يرفض أي تسلسل مواد غير متصل، وأي حرف بديل (U+FFFD)، وأي أخطاء معروفة في ترتيب «لا».

**ضمانات البيانات:**
- رقم المادة يُقبل فقط إذا طابق نمط الترقيم في الوثيقة وكان تاليًا للمادة السابقة مباشرة.
- لا يُخترع رقم مادة للنصوص غير المرقمة، فتُعرض باسم القسم.
- لكل مقطع: المعرّف، ورقم المادة، وصفحة PDF الفعلية، والصفحة المطبوعة إن اختلفت، والباب أو الفصل، والنص الأصلي، والإحالات المكتشفة (مثل «المادة الخامسة من النظام» تُربط بالنظام الأم).
- المادة الطويلة تُقسم عند حدود البنود المرقمة فقط. يُرفق مطلع المادة مع كل جزء، ويُشار إلى الجزء (1 من 2).
- النص المعروض اقتباسًا هو النص الأصلي. التطبيع، أي توحيد الهمزات وإزالة التشكيل، يُطبق على نسخة البحث فقط.

## 7. البحث المحلي

`src/search.ts`: بحث BM25 داخل المتصفح يعمل على مستويين، المقطع كاملًا وكل بند فيه.
- تطبيع عربي (الهمزات، التاء المربوطة، الألف المقصورة، التشكيل، التطويل) وتجذيع خفيف.
- قائمة مصطلحات متقاربة، مثل: إعلان/دعاية/ترويج، تبغ/سجائر، ترخيص/تصريح/فسح، خصوصية/صور.
- يُلحق بالنتائج المواد المحال إليها (مستوى واحد)، والتعريفات إذا ورد مصطلح معرَّف في المدخل.
- في «فحص نص» تُضمَّن دائمًا ضوابط المحتوى العامة: نظام الإعلام المرئي والمسموع م5، ولائحته م4، ونظام المطبوعات م9، ولائحته م73. هذا يقلل احتمال أن يفوت البحث اللفظي ضابطًا عامًا.
- إذا لم يعثر البحث على مقاطع مطابقة لسؤال، يعرض معيار «لا تكفي المراجع المتاحة للتقييم» محليًا **دون طلب مدفوع**، مع خيار صريح «أرسل رغم ذلك».
- يوضح الموقع أن البحث قد لا يسترجع كل مادة ذات صلة.

## 8. تكامل المزودين: ما اختُبر وما لم يُختبر

| المزود | الحالة |
|---|---|
| **Anthropic (Claude)** | **أُعيد اختبار الاتصال المباشر من المتصفح بتاريخ 2026-11-02** بطلب حقيقي من Chromium بمفتاح غير صالح عمدًا (`tests/cors-check.cjs`): دون الترويسة `anthropic-dangerous-direct-browser-access: true` يحجب المتصفح الطلب، ومعها يصل خطأ المصادقة 401 مقروءًا. أسماء النماذج والأسعار من صفحات Anthropic الرسمية. يُرسل `output_config.effort: "medium"` (موثق لـ Sonnet 5.5 وHaiku 5.5 وOpus 5.5 في صفحة effort الرسمية) و`max_tokens: 8000`. **لم يُختبر تحليل كامل بمفتاح صالح.** |
| **OpenAI** | من سجل المشروع السابق: جلب قائمة النماذج من المتصفح نجح، ووصل طلب `POST /v1/responses` وأعاد ردًّا مقروءًا (429 `insufficient_quota`). **في هذه الجولة تعذر الوصول إلى `api.openai.com` وصفحات OpenAI الرسمية من بيئة التنفيذ**، فلم يُعد الاختبار، ولم تُوثّق أسماء النماذج أو أسعارها. يُختار النموذج من قائمة حساب المستخدم، ويُعرض للمستخدم مع تنبيه «لا يتوفر سعر موثق» قبل الإرسال. **لم تُختبر نتيجة تحليل كاملة.** |

روابط إنشاء المفاتيح: `https://platform.claude.com/settings/keys` (تفتح وتطلب تسجيل الدخول)، و`https://platform.openai.com/api-keys` (لم يمكن فتحها من بيئة التنفيذ).

## 9. المفتاح والخصوصية

- المفتاح في متغير داخل ذاكرة الوحدة `src/providers.ts` فقط. لا يُحفظ في `localStorage` أو `sessionStorage` أو IndexedDB أو الكوكيز، ويُمسح عند إعادة التحميل أو عند الضغط على «مسح المفتاح» أو عند `pagehide`.
- يُرسل المفتاح في ترويسة المصادقة إلى نطاق المزود الرسمي فقط. لا يوضع في عنوان URL ولا في نص المحادثة، ولا يُطبع في السجلات.
- رسائل الخطأ لا تعرض نص خطأ المزود، لأن بعض المزودين يُضمّنون جزءًا مقنّعًا من المفتاح فيه. تُعرض رسالة عربية مع رمز الاستجابة ونوع الخطأ فقط.
- قبل الإرسال يلزم تأكيد الموافقة على إرسال النص والمراجع المختارة إلى المزود.
- لا يُرسل أي طلب (مدفوع أو مجاني) أثناء الكتابة أو لصق المفتاح. عند الضغط على التنفيذ: طلب مجاني لقائمة النماذج، ثم طلب تحليل واحد. لا محاولات تلقائية مدفوعة، والنقر المتكرر لا ينشئ طلبًا ثانيًا.
- مخرجات النموذج تُعرض نصًا عبر `textContent` فقط، ولا يُنفذ أي HTML.
- CSP: `default-src 'none'`، والسكربتات من `'self'` فقط، والاتصال محصور في `api.anthropic.com` و`api.openai.com`.
- لا موارد من نطاقات خارجية: Three.js والخطوط مضمّنة في البناء من الموقع نفسه، ولا أدوات تتبع.
- لا يوضع محتوى المستخدم في أي رابط.

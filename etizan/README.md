# اتزان

مساعد مالي يومي لأبو تميم. أول ما يفتح التطبيق يشوف وضعه: كم باقي يقفّل اليوم، كم المتاح للصرف، كم دخل من أوبر، والالتزامات القادمة. وفيه مساعد يفهم الكلام (بالصوت أو بالكتابة) ويسجّل ويرد باختصار.

- عربي بالكامل وRTL، مصمم للجوال أولًا، ويُثبَّت كتطبيق PWA ويشتغل بدون إنترنت بعد أول فتح.
- عداد ثلاثي الأبعاد (React Three Fiber) هو قلب الشاشة، وله خمسة أوضاع: تقفيل اليوم، المتاح، أوبر اليوم، التغطية، الشهر.
- البيانات محفوظة في المتصفح على نفس الجهاز (localStorage). من الإعدادات تقدر تحفظ نسخة احتياطية JSON وترجعها.

## التشغيل

```bash
cd etizan
npm install
npm run dev        # http://localhost:3000
npm test           # اختبارات المحرك المالي والمحلل
npm run build      # نسخة ثابتة في out/
```

النشر على Vercel: اختر Root Directory = `etizan`. أو ارفع مجلد `out/` على أي استضافة ملفات ثابتة.

## المنطق المالي (`src/lib/finance/engine.ts`)

| المفهوم | الحساب |
|---|---|
| الدخل الثابت | مجموع المصادر = 15,466 |
| الالتزامات الثابتة | مجموع الالتزامات النشطة هذا الشهر = 16,391 (المؤقتة تنتهي تلقائيًا بعد مدتها) |
| الفواتير غير الثابتة | الكهرباء: المسجّل فعلًا هذا الشهر، وإذا ما انسجل شيء يُحجز متوسط النطاق (500) |
| **عجز الشهر** | الالتزامات + الفواتير − الدخل الثابت = 1,425، ويُغطّى من أوبر |
| **المطلوب تقفيله اليوم** | (باقي العجز + أي تجاوز سابق) ÷ أيام العمل المتبقية، ويُضاف له مصروف اليوم اللي ما يغطيه المتاح |
| المتبقي من هدف اليوم | المطلوب تقفيله − دخل أوبر اليوم |
| **المتاح للصرف** | دخل أوبر الزائد عن هدف كل يوم، ناقص مصاريف المعيشة |
| المحجوز للالتزامات | الدخل الثابت + المغطّى من العجز |
| نسبة التغطية | المحجوز ÷ (الالتزامات + الفواتير) |
| توقع نهاية الشهر | بمعدل أوبر وبمعدل الصرف الحاليين |

الشهر يُعاد حسابه يومًا بيوم من السجل كله، فأي تعديل أو حذف يحدّث كل الأرقام. اليوم اللي ما انشغل فيه، ينتقل نصيبه للأيام الباقية. أيام العمل الافتراضية من الأحد إلى الخميس، وتتعدل من الإعدادات.

## التحكم اليدوي بالأهداف (`src/lib/finance/manual.ts`)

- **هدف اليوم:** تحدد أنت كم تحتاج تقفل اليوم، وهذا الرقم يتقدم على التلقائي. ما يغطيه هدفك من عجز الشهر يتوزع تلقائيًا على باقي الأيام.
- **هدف يومي ثابت:** رقم واحد لكل أيام العمل، وتقدر ترجع للتلقائي في أي وقت.
- **دخلت حتى الآن:** تكتب مجموع دخل اليوم. إذا الرقم أكبر من المسجل تنضاف الزيادة كإدخال جديد، وإذا أصغر ينخصم الفرق من أحدث الإدخالات.
- من الواجهة: زر «حدّد هدف اليوم» في الرئيسية، أو زر الضبط جنب «سجّل دخل أوبر»، أو من صفحة أوبر. وفي الشاشة معاينة فورية قبل الحفظ.
- من المساعد: «هدفي اليوم 200»، «ابي اقفل اليوم 180»، «خل الهدف اليومي 150»، «رجع الهدف تلقائي»، «دخلت حتى الآن 120».

## المساعد (`src/lib/assistant/`)

- `normalize.ts` و`numbers.ts`: توحيد النص العربي والأرقام (١٢٠، 120، «مية وعشرين»).
- `parser.ts`: يحوّل النص إلى Intent، مثل: مصروف (أكثر من مصروف في جملة وحدة)، دخل أوبر، سؤال، تصحيح («لا مو 120، كانت 110»)، تعديل («عدل البنزين إلى 90»)، حذف، تراجع.
- `actions.ts`: ينفّذ الـ Intent على البيانات ويطلع رد قصير يبدأ بـ «هلا أبو تميم،».
- `brain.ts` و`llm.ts`: طبقة جاهزة للربط مع نموذج لغوي عن طريق خادم وسيط. النموذج يرجّع نفس شكل الـ Intent، وإذا فشل الطلب يرجع التطبيق للمحلل المحلي.

الصوت (`src/lib/speech/`): يستخدم Web Speech API بالعربي السعودي (`ar-SA`)، وتقدر تستبدله بخدمة تفريغ صوتي على الخادم بنفس الواجهة. الرد يُقرأ بالصوت إذا كان السؤال بالصوت، وهذا يتعطل من الإعدادات.

## البيانات (`src/lib/types.ts`)

`incomeSources` · `fixedObligations` · `variableExpenses` · `uberEntries` · `dailyTransactions` · `assistantMessages` · `obligationPayments`، و`MonthlySummary` يُشتق منها دائمًا. البيانات الأولية في `src/lib/seed.ts`.
لربط قاعدة بيانات: استبدل `storage` في `src/lib/store.ts`. كل إجراء يرجّع `AppData` كاملة جديدة، فالمزامنة سهلة.
